# TechPulse AI

AI, technology and the future explained.

## Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4
- Static/server-rendered article pages
- Built-in metadata, sitemap, robots and Article structured data

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Current status

Phase 1 foundation is in place:

- Responsive publication homepage
- Article content model and article pages
- Three launch articles
- About, Contact, Privacy and Terms pages
- SEO metadata
- XML sitemap generation
- robots.txt generation
- JSON-LD Article markup
- GitHub Actions build verification

## Before production launch

1. Replace `https://techpulse-ai.example.com` with the production domain in `app/layout.tsx`, `app/sitemap.ts`, and `app/robots.ts`.
2. Add a real editorial/contact email.
3. Add analytics and Search Console verification.
4. Add consent management before enabling personalized advertising where required.
5. Expand the editorial library with original, high-quality content before applying to AdSense.
6. Add newsletter provider integration.
7. Add article imagery and Open Graph images.
8. Deploy to a production host and validate Core Web Vitals.

## Editorial strategy

Primary launch clusters:

- AI tools, comparisons and practical reviews
- AI tutorials and workflows
- AI/technology explainers

Secondary coverage can expand into coding, cybersecurity, gadgets, startups and major technology developments once topical authority is established.
